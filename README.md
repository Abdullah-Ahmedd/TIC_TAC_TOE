# 🎮 Tic-Tac-Toe Game

A modern, interactive implementation of the classic Tic-Tac-Toe game built with web technologies. Features multiple game modes including human vs human and human vs AI gameplay with different difficulty levels.

![Game Preview](https://github.com/Abdullah-Ahmedd/TIC_TAC_TOE/releases) 

## 🚀 Features

- **Multiple Game Modes**
  - 👥 Human vs Human
  - 🤖 Human vs Easy AI (Random move)
  - 🤖 Human vs Medium AI (Priority: attack ,deffence and then random moves)
  - 🧠 Human vs Hard AI (Minimax algorithm - Unbeatable)
  
- **Modern UI/UX**
  - Responsive design that works on all devices
  - Smooth animations and transitions
  - Clean, intuitive interface
  - Visual feedback for game states

- **Game Features**
  - Real-time score tracking
  - Game history
  - Reset functionality
  - Winner detection and celebration
  - Draw/tie game handling
  - 

## 📋 How to Play

1. Choose your game mode (Human vs Human or Human vs AI)
2. Players take turns placing X's and O's on the 3x3 grid
3. First player to get 3 in a row (horizontally, vertically, or diagonally) wins
4. If all 9 squares are filled without a winner, the game is a tie
